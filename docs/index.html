hwatu

A headless browser that runs on the user's machine and is driven by agents through a CLI and MCP. Target platforms: Linux, macOS, Windows.

curl -fsSL https://raw.githubusercontent.com/hongnoul/hwatu/main/scripts/install.sh | bash

GitHub · Releases · MIT · Linux today

Quick start

hwatu doctor
hwatu goto localhost:3000
hwatu snapshot                  # page state as data
hwatu click @e3
hwatu type @e5 "Test User"
hwatu expect text "Saved"
hwatu shot /tmp/after.png
hwatu show                      # render the live session for a person

Full command reference: docs/agents.md. Measurements: docs/benchmarks.md.

Skills

Skills live in the agent harness. A skill is a SKILL.md that calls hwatu commands. This project has no skill library or registry.

Human involvement

The browser is headless and becomes visible only through show. Login walls and irreversible actions return structured stops that the agent relays to the user. CAPTCHAs are handled by the agent with challenge, shot, click --trusted, and type.
